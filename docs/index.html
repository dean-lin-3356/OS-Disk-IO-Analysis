01 / INTRODUCTION

研究背景與目的

磁碟 I/O 是作業系統管理儲存資源的重要環節。 不同應用程式所產生的讀寫請求，在操作頻率、 請求大小、存取位置及回應時間上可能具有不同特性。

本專題使用 MSR Cambridge Block I/O Traces， 分析真實儲存系統的工作負載，並探討其與 作業系統 I/O Management、Caching 及 Storage Access Locality 的關係。

Research Questions

RQ1

Read/Write Workload

讀取與寫入操作在操作比例、 請求大小及 I/O 強度上有何差異？

RQ2

Response Time

操作類型、請求大小及工作負載強度 與回應時間有何關係？

RQ3

Access Locality

儲存工作負載具有何種存取區域性， 其對快取及 I/O 管理有何意義？
